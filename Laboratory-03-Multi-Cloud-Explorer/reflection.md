# Reflection

This laboratory helped me understand the differences between AWS, Microsoft Azure, and Google Cloud Platform. I learned that each cloud provider offers different services and strengths.

I also learned that choosing a cloud platform should depend on the requirements of the client. Factors such as cost, scalability, security, available services, and technical requirements should be considered before selecting a platform.

## Mission Reflection

The mission of this laboratory is to develop my understanding of different cloud computing platforms and how they can be applied to real-world organizations. Through researching AWS, Microsoft Azure, and Google Cloud Platform, I learned how to compare their services, advantages, infrastructure, and possible applications.

This activity also helped me develop my ability to make appropriate cloud platform recommendations based on a client's needs. I realized that there is no single cloud platform that is best for every organization because the right choice depends on factors such as budget, business requirements, existing technologies, scalability, security, and technical expertise.

Overall, this laboratory improved my knowledge of cloud computing and helped me understand how cloud platforms can support modern businesses and organizations.
