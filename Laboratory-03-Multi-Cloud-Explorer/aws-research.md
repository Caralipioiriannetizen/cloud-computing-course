# AWS Research

## Overview

Amazon Web Services (AWS) is a cloud computing platform that provides computing, storage, database, networking, security, and other cloud services.

## Major Services

- Amazon EC2
- Amazon S3
- Amazon RDS
- AWS Lambda
- Amazon VPC

## Advantages

- Wide range of services
- Highly scalable
- Global infrastructure
- Flexible pricing options

## Disadvantages

- Can be difficult for beginners
- Large number of services can be confusing
- Costs must be monitored carefully
