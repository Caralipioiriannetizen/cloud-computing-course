## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

Amazon Web Services (AWS) offers one of the broadest ranges of cloud services among the three major providers. It provides services covering computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the best integration with Microsoft technologies because it is developed and operated by Microsoft. It works closely with products and technologies such as Windows Server, Microsoft 365, Active Directory, and other Microsoft enterprise solutions.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud Platform (GCP) is particularly strong in artificial intelligence, data analytics, and Kubernetes. Google developed Kubernetes and provides Google Kubernetes Engine (GKE), while also offering a wide range of AI and machine learning services.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Amazon Web Services (AWS) because it offers a broad range of cloud services and provides flexible options for different types of applications. AWS is also suitable for learning cloud computing because it provides many services that can be used for different projects and workloads.
